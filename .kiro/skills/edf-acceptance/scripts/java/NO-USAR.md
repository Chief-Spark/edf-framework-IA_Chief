# Generador Java deprecado: no compilar ni ejecutar

Desde la versión 1.6.0 del framework (2026-11-18), la skill `edf-acceptance` genera con
`scripts/render_templates.py` (Python, sin compilar). Esta carpeta se conserva solo como referencia
histórica. No ejecutes `mvn`, `javac` ni `java -jar` sobre ella. Ver `../DEPRECADOS.md`.
